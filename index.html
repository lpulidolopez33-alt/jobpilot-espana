🔐 Privacidad y límites reales

Tus candidaturas y CV se almacenan localmente en este navegador. No hay sincronización entre Windows e iPhone ni lectura automática de Gmail: ambas funciones necesitan una cuenta y un servicio de sincronización, o una conexión externa configurada. La comprobación de vigencia se realiza abriendo la fuente original; un enlace accesible por sí solo no demuestra que una oferta siga abierta. Usa Exportar/Importar para mover datos entre equipos. No uses este equipo si es compartido.

☁️ Sincronización iPhone ↔ Windows

Opcional: configura tu proyecto gratuito Supabase. La sincronización funciona entre dispositivos conectados a internet. No compartas tu contraseña ni utilices la clave service_role.

Las candidaturas y el perfil se sincronizan mediante un documento compartido con control de versiones. En caso de cambios simultáneos desde dos dispositivos, la app no sobrescribe automáticamente: solicita resolver el conflicto. El CV local no se sube. Para mayor seguridad, utiliza una contraseña única.
